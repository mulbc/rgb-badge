# Unrouted VLED local placement check, 2026-10-06

The source is the [unlinked converter schematic](../../hardware/coupon/rev-a/staging/vled-converter.kicad_sch) and its [separate local KiCad placement](../../hardware/coupon/rev-a/staging/vled-layout-trial.kicad_pcb). This is **not** the coupon or final-board PCB. No board exists and no hardware measurement or firmware revision applies.

KiCad's bundled Python 3.9 regenerated the placement deterministically from the current 13-part / 39-logical-pin native XML netlist, exact project-local footprints and the [fit-screen coordinates](../../mechanical/review/fit-trial.json). A saved-board round trip checked all thirteen references, footprint library IDs, orientations, centres and numbered pad nets. The current file SHA-256 is `8907f5d51f93211c5d67e74254ece1e54f7e37bc4bd41e7e03c4ecb85d956cec`; successive generation is byte-stable. KiCad CLI 10.0.6 loaded and plotted the original pad/courtyard arrangement, which was visually inspected. The subsequent 180° feedback-resistor reordering was checked against native pad coordinates and rerun through DRC. The local board has no tracks, vias or copper zones. Reference fields are hidden on this local trial because their final positions belong to full-board silkscreen placement.

The sandboxed standalone `kicad-cli pcb drc` aborted with exit 134 before creating a report, also on a one-footprint control board. The macOS crash log shows the DRC path calling AppKit mouse-position code before the abort. Running KiCad CLI with desktop access succeeded. The [raw native DRC report](vled-layout-drc-2026-10-06.json) has **zero geometry violations** and **thirty unconnected items** on the local, unrouted study. The latter are expected because no tracks or zones exist; this is **not** a complete-board DRC pass. The root coupon schematic still has zero configured ERC violations and 410 components / 1,537 logical pins. Those are different checks.

Follow-on: a [separate partial routing study](vled-routing-trial-2026-10-06.md) now connects the inductor and nearest input/output capacitor positives with twelve short segments. Its local DRC reports zero geometry violations and twenty remaining open connections. The grounded divider pad was moved nearer the control-GND pin without changing the cluster envelope, but its route and return path remain open. The accepted [ADR 0021](../decisions/0021-external-battery-current-measurement.md) resolves the baseline INA232 population assumption for capture. Heat, other circuits and complete-board DRC remain open before independent Gate A review.
