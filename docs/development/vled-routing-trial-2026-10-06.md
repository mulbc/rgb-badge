# Partial VLED routing study, 2026-10-06

The [standalone KiCad board](../../hardware/coupon/rev-a/staging/vled-routing-trial.kicad_pcb) adds twelve front-copper segments to the [13-footprint placement study](../../hardware/coupon/rev-a/staging/vled-layout-trial.kicad_pcb). [Its generator](../../tools/generate-vled-routing-trial.py) connects both IC pins for each inductor terminal, both input-capacitor positives to VIN, and the two closest output-capacitor positives to VOUT. It loads the actual schematic-net-assigned footprints. Regeneration is byte-stable; board SHA-256: `e5960840242f96a9ba85c7662e1916e51f99e30950146d56ebcc3075f0a575eb`.

KiCad CLI 10.0.6's [raw native DRC report](vled-routing-drc-2026-10-06.json) shows **zero reported geometry violations and twenty unconnected items**. The previous unrouted version had thirty unconnected items. All routed segments are 0.20 mm wide and serve only to test connection and clearance geometry; no current capacity, switching performance or thermal margin is established. The board has no ground copper, feedback route, vias, interlock, LED load, other power stages or mechanical stack. It is not the coupon or final-board PCB. No physical hardware, firmware revision or measurement exists.

The initial positive-side paths can be drawn in this bay without native DRC conflicts. The next converter-layout correction is the control network: the `R84`/`R85`/`R86` divider currently spans x93.25–99.55 at y22.8–23.8 mm, while U37's FB and control-GND pins lie at (92.95, 26.05) and (92.45, 26.05) mm. This is an XY placement observation, not an electrical measurement. [TI's TPS63020 layout instructions](https://www.ti.com/lit/ds/symlink/tps63020.pdf#page=24) call for the feedback divider near control ground, short separated control-ground traces, and short/wide power and ground paths. Repack the divider and reserve a return path before treating this as a converter layout candidate. The complete board must then receive routed DRC, thermal/current review and independent Gate A review before fabrication.
