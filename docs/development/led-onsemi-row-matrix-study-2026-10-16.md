# Numbered onsemi row pads on the complete-matrix trial

The [generated board](../../hardware/coupon/rev-a/staging/led-qt-uniform-2p2-onsemi-row-trial-114mm.kicad_pcb) replaces the sixteen netless Diodes pair **review footprints** in the [2.2 mm QT matrix study](led-qt-uniform-2p2-matrix-study-2026-10-16.md) with exact `NTLJD3119CTBG` onsemi footprints and numbered candidate nets. It uses the same pin mapping already checked in the [standalone candidate schematic](onsemi-row-pair-capture-and-placement-2026-10-14.md): pin 1 GND, pin 2 selected row, pin 3 LED anode, pin 4 VLED, pins 5/6 row gate. The [generator](../../tools/generate-onsemi-row-matrix-trial.py) leaves the canonical root schematic, row sheet and BOM unchanged; this mixed-source board is not a schematic-synchronized fabrication candidate.

One actual test route joins `PAIR01` pin 3 to the matrix's complete `ROW_00_A` bus through a short B.Cu trace, 0.50/0.30 mm through-via and In3.Cu trace. The local via at (104.5, 7.1) mm clears nearby decoder pins; an initial site at (105.0, 6.4) mm failed native clearance and hole-spacing checks. Native [KiCad DRC](led-qt-uniform-2p2-onsemi-row-drc-2026-10-16.json) retains only **104 intrinsic fine-pitch pad-gap findings**, with no added geometric finding. Full open edges are **661** after assigning all row-pair pads and connecting only row 00. The board regenerated twice with SHA-256 `9880a657f3ded907dc2d2935ca60cf6ddcb85d0e257d9f53b7c4ddbe85dd3df6`.

The remaining fifteen row pairs are scattered from x ≈ 12 to 113 mm by the first-fit placement, so their fanout requires either a more ordered placement or multi-layer routing. Every matrix colour column also still needs its driver connection. Onsemi's mask/stencil recommendation, row-current heat, board-side height, the proposed QT pitch, all power/control routes, enclosure fit and independent Gate A remain unresolved. This source check is not a built-board test or a package approval.
