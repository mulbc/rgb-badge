# Display interlock local placement trial, 2026-10-13

This is an **unrouted local KiCad study**, not the coupon PCB or a fabrication source. `tools/generate-display-interlock-layout-trial.py` exports the root schematic netlist and places all nine captured interlock ICs (`U47`–`U55`), nine bypass capacitors (`C66`–`C74`), eleven support resistors (`R103`–`R113`) and two isolated-output test pads (`TP13`, `TP14`) with their exact project-local footprints and exported pad nets. The study area is 35 × 24 mm in local coordinates; it makes no claim that this block fits the 108 mm coupon, RF clearance or enclosure.

The deterministic native-board round trip found **31 footprints and 103 unique numbered pad assignments**, with every IC and its bypass capacitor in a local group. KiCad 10.0.6 native PCB DRC found **eight copper-clearance violations** and **76 expected unconnected items**. All eight geometric violations are between adjacent pads inside `U48` and `U52`, the exact TI `DSF0006A` 0.35 mm-pitch footprint: the manufacturer-derived lands leave **0.18 mm** copper gap versus the current default **0.20 mm** board clearance. There were no inter-footprint geometry violations in this isolated board. The eight violations are real open design-rule findings, not waived by this study. Resolve the manufacturable local clearance rule or use a different package before accepting a routed board; preserve the manufacturer's land dimensions until reviewed. The 76 opens will remain until routing, so the study has no PCB DRC pass.

The paired-row candidate `DMC1229UFDB-7` has a separate **0.15 mm** edge-to-drain gap in the manufacturer's suggested Type B land pattern; its [library audit](../../hardware/coupon/rev-a/dual-row-package-library-audit.md) records the conflict with the same 0.20 mm global clearance. Neither fine-pitch exception has been accepted. These are manufacturing-process questions, not evidence that changing the schematic alone produces a routable board.

To reproduce, run the generator with KiCad's bundled Python, then run `kicad-cli pcb drc --format json --output <report.json> hardware/coupon/rev-a/staging/display-interlock-layout-trial.kicad_pcb` with the native GUI runtime available. Inspect `.violations` and `.unconnected_items` separately. No hardware measurement or independent review has occurred.
