# Provisional E1 charger-gate capture, 2026-10-11

The root-linked `charger-gate.kicad_sch` implements [ADR 0026](../decisions/0026-charger-e1-gate-network.md) with exact TPS259474ARPWR E1, U42/U43 SN74AUP1G125DBVR sinks, exact 220 kΩ/270 kΩ enable divider, 3.32 kΩ ILM resistor, 2.2 nF C0G dVdt capacitor, and local input/output and logic bypass capacitors. The earlier U40 temperature sink shares `CHARGER_GATE_EN`. U42 OE joins `USB_CHARGE_REQ`; U43 OE joins `USB_RAW_LOGIC_READY`. E1 OUT joins BQ24074 IN and the local EN2 clamp; E1 IN retains one explicitly nonphysical `USB_PROTECTED_DRAFT` source flag until E0 is designed. The previous BQ IN source flag has been removed. This is a connected *source* checkpoint, not a charger operating result.

Pin/land review: E1 pins 1–10 and the RPW0010A footprint use the existing project-local TI TPS25947 audit. U42/U43 reuse the audited TI AUP DBV5 pin-to-pad map (OE 1, A 2, GND 3, Y 4, VCC 5). R94–R96 use the already audited Panasonic ERJ2 0402 two-pad land; the newly exact-valued symbols retain passive pins 1/2. C57 uses the already audited Murata GRM15 0402 land with passive pins 1/2. C56 reuses the project-local GRM18 0603 land. The manufacturer part numbers and datasheet links are embedded in the deterministic generator and cached KiCad symbols; the gate checker compares every component value/footprint and all 36 pin nets against native XML. Source audit does not establish purchased-part markings, solder quality or effective capacitance.

First-author validation on macOS with KiCad CLI 10.0.6: `tools/check-kicad.sh` completed all source and library checks, exported controlled symbol and footprint SVGs, and produced a **zero-configured-violation** ERC report. The native full netlist contained **439 PCB items and 1,630 logical pins**. The E1 checker matched 11 exact components/36 pins and the cross-sheet joins to U40, U41, U17 and U34. The full schematic PDF exported as 17 pages, with page 17 rendered and visually inspected for readable pin numbers, nets, NC marks, draft source flag and title. The generated PDF used the A2 root / A3 E1 sheet arrangement. Raw transient files for the focused native review are `/private/tmp/rgb-e1-gate-20261011.xml`, `/private/tmp/rgb-e1-gate-erc-20261011.rpt`, `/private/tmp/rgb-e1-gate-review-20261011.pdf` and `/private/tmp/rgb-e1-gate-page17.png`; the source generator/checkers and canonical schematic are the durable evidence. The static divider screen is a **calculation** with an assumed aggregate 1.6 µA leakage, not a guarantee or bench test.

No PCB, firmware, cell, supply, oscilloscope or thermal fixture was used; there are **no hardware measurements**. E0 input protection, delivered pack polarity/header, partial-rail behavior, startup and brownout, fault and reverse energy, inrush and capacitor DC-bias, BQ EN2 clamp load, whole-port current, thermal fit, and independent Gate A review remain open. The 3.32 kΩ E1 ILM TI test point of 0.850–1.150 A is distinct from the lower fixed BQ input setting and is not a verified USB source ceiling. This source checkpoint does not authorize fabrication.
