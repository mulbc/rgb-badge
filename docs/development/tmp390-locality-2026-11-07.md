# TMP390 cold-programming locality: selected 40-open study

[ADR 0094](../decisions/0094-tmp390-programming-resistor-locality.md) selects a
local R90 placement and exact one-track ground-return replacement in the
[remaining-routing successor](../../hardware/coupon/rev-a/staging/led-remaining-routing-trial-114mm.kicad_pro).
It reaches **40 native and physical opens**, retaining the exact **104 existing
intrinsic DRC findings**. This is unbuilt Coupon Rev A CAD geometry; there is
no powered hardware, firmware revision or bench measurement.

## Geometry and source identity

R90 stays **Panasonic ERJ2RKF1402X, 14 kΩ, 1%**, with identical local pads and
fields. U39 stays TMP390A2DRLR at its accepted thermal location. R89's pose,
hot-programming value and copper remain unchanged. No source/cell/charger/LED/
regulator current limit, temperature setting, NTC/protection, default-disabled
permission or firmware changes occur.

R90 moves from (34.75,11.75) mm, 180° B.Cu to (60.00,16.75) mm, 0° B.Cu.
Its cold pad is now 1.688409 mm from U39.2 rather than 23.417210 mm; these are
CAD pad-centre distances, not old/new trace lengths. R90.2 is 2.262902 mm from
U39.3, and both ground pads touch the same individual filled B.Cu ground
polygon. Three ordinary 0.20 mm cold tracks total 2.385 mm and physically join
U39.2–R90.1. No new via is added.

The R90-only screen found 94 courtyard/copper-clear poses but no clear direct,
L-shaped or tested extra-bend B.Cu route. R89's GND return enclosed the exit.
The exact 1.500 mm GND track (59.865,16.000)–(58.365,16.000) mm is therefore
replaced by five ordinary-width local B.Cu tracks totaling 5.770 mm. Both
original endpoints and all five direct original-layer contacts survive,
including the IC ground pad, R89 feed and existing branch. Every other
accepted copper item survives. The longer return and parasitic/quiet-ground
behaviour require separate electrical qualification; plane continuity is not
an impedance or noise result.

## References and validation

TI TMP390 Rev A section 10.1 / Figure 10-1 recommends local programming
resistors to limit leakage and parasitic capacitance. Pin functions on page 3
and the layout example on page 18 were read visually. Panasonic's
29-May-2025 ERJ reference, page 4, retains the ERJ2R package dimensions;
no footprint geometry is changed. These are reference sheets, not signed
approval/delivery specifications.
