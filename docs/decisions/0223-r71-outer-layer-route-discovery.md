# ADR 0223: Fixed R71 outer-layer route discovery

Date: 2026-11-19
Status: Accepted for bounded read-only native discovery only.

ADR0222's exact edge/centre-transition proposal is blocked by retained
copper on several layers; no PCB or source change follows. Keep its exact
26-open source, R71 identity/pose/value, all parts, source copper and rules.

Discover ordinary 0.20 mm B necks from actual isolated R71.1, bounded to
2 mm length and 1.5 mm radius, using 0.050 mm eight-neighbour native steps.
At actual reachable nodes screen only supported B/In4 0.30/0.10 mm captures
against every source/mutual copper and full-board hole policy. Prefer an
off-pad drill and preserve actual 0.500 mm copper-edge clearance. Allow no
new central transition, through via, source retirement or part move.

From at most sixteen nearest valid gateways, discover ordinary 0.20 mm In4
routing to actual retained main VBUS_CONNECTOR In4 copper. Use individually
witnessed source endpoints/interior points, exact native joining leads and
actual board outlines; no fictitious zone or disconnected same-net target.
Bound the full new ordinary B+In4 conductor length to 112 mm and the sparse
0.050 mm eight-neighbour graph to 150,000 expanded nodes. All other sources
stay fixed. A node-bound miss is not graph exhaustion or an impossibility
claim. Write no PCB.

A complete candidate needs a separately frozen exact prototype plan, all
214 source groups and retained attached copper, complete supply/ground
contacts, matching reduced counts, exact104 and every source/serialized/
replay/inverse/hole/orphan/fault/visual gate before selection. Current limits,
all electrical/return/sense-noise/assembly/fit/stack/process/Gate A and
fabrication holds remain unchanged.
