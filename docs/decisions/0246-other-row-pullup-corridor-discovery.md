# ADR 0246: Other row pull-up corridor discovery

Date: 2026-11-20
Status: Accepted for bounded read-only discovery.

The expanded R9 screen finds no complete pose among73,884 placements;
63,258 fail courtyards,8,784 pads and1,842 lead templates. The finer5,324
corridor placements yield5,106 courtyard failures and218 pad failures.
Original ROW_SEL_02/04 and ROW_02_A, among other exact witnesses, occupy
those pads. Do not retire selectors or move through vias on this evidence.

On the same immutable23-open source, independently screen exact existing
ERJ2RKF1001X R10/R12/R13 on B with every other part and all source copper
retained. Gate targets are respectively actual three-pad PAIR05/PAIR07/
PAIR08 gate groups; supply targets are main-group PAIR06/PAIR08/PAIR08.4.
Witness original source group memberships from native data before screening.

For each part use x=77.500–78.000 mm at0.050 mm increments and y within
3 mm of its target package centre, at0.050 mm increments, with four cardinal
orientations. Keep actual B courtyards, native pads, ordinary0.20 mm leads,
power≤6 mm and gate≤12 mm; use direct and both orthogonal one-bend
lead templates, checking source and mutual copper. No flip, substitution,
field/pin/net/local package change, current/default-off change, new via,
source retirement or PCB write is permitted. No source selector or through
via may move. A success still needs exact private-leaf/contact freezing and
all original-group/attached-copper, exact104, replay/inverse/fault/visual
successor gates. All timing/return/thermal, trial part, controlled-stack/
process, fit and independent Gate A/fabrication holds persist.
