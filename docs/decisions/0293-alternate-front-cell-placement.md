Date: 2026-11-24
Status: Accepted for bounded RAM-only placement/access discovery.

The first frozen cell preserves real power/gate/ground and selector but
has no accepted row route in the bounded supported-layer studies. Keep
it unselected. Revisit the already source-screened32 front PAIR05 poses
and28 short-R10 modules, prioritizing90-degree PAIR orientation and
