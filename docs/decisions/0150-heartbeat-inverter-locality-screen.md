Date: 2026-11-14

fixed-pose U48 capture within the existing neck bound. Screen exact U48

function, current/protection/NTC/timer/fail-safe/default-off boundary or rule may

complete native/physical/finding/replay/inverse/fault/source/visual gates and
all electrical/part/process/stack/fit/Gate A holds remain mandatory. This
screen neither selects a successor nor authorizes fabrication.
