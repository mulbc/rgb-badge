Date: 2026-11-16
Status: Accepted for read-only complete-interface discovery only.

retain that original colour track and consider only original ROW_SEL_06 In4
track 5600f32c-2585-5391-b9e4-55a8f71323a0, (55.700,15.750)–(57.800,15.750)
mm, width 0.200 mm. Freeze its native source contacts before omission.

three-segment In3 paths with intermediate y=14.000–17.000 mm in 0.050 mm

optional aligned In3/In4 access. Original copper/edge/hole rules and complete

separate complete-prototype scope, full selector/supply continuity, all 216
original groups, matching reduced native/physical count, exact104 and every
source/replay/inverse/contact/hole/orphan/fault/visual gate. All electrical,
