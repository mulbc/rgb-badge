# ADR 0284: Supply bridge between existing inner-layer ports

Date: 2026-11-24
Status: Accepted for bounded RAM-only additive continuity discovery.

ADR0283 classifies223 actual six-pad and429 actual34-pad captures, but
its direct/L F bridges do not qualify. Native tracing also identifies
existing VLED Cu on both In2 and In3. The nearest In2 ports are about
3.60035 mm apart. Test a real ordinary0.20 mm conductor between actual
existing six-/34-pad Cu on either one of those layers, with no new via.

Keep the exact ADR0279 cell/111-item cohort and the real rejected ROW04
path. Search independently on In2 then In3, x76..83/y9..16 mm,
0.025 mm/100000 states, at most6 mm added supply conductor. Starts and
goals must be actual retained source copper proved in the respective
native supply groups. No virtual pad, source retirement, new drill,
centre transition, clearance/width/profile/current/protection change.
Existing unsupported source transitions remain explicitly held; attaching
ordinary copper does not qualify their fabrication topology.

Require native Cu and refill at21 matching opens, VLED40/GND197/row18/
gate4, every original group except explicitly pending selector, all19256
retained attached source Cu and zero orphans. Only final20 opens/all210
old groups may advance to a separate frozen PCB prototype. Write no PCB.
Full power-current-sharing/electrical/return/thermal/trial-package/stack/
process/assembly/fit/independent Gate A holds persist; fabrication is
prohibited.
