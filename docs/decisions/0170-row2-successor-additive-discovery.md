# ADR 0170: Additive discovery from the complete row-two successor

Date: 2026-11-15
Status: Accepted for ignored bounded routing studies only.

Use immutable selected 28-open row-two source SHA-256
`1723cb53524f7907c784cc401e3b73c5e0ee93b667dedd246a87bf60c673ac34`.
The exact passive exchange frees the old R37 selector corridor. Recheck additive
ordinary 0.20 mm routes for remaining VLED/GND and row-gate groups with every
part and original copper item retained. Use exact source profiles/rules, actual
0.500 mm copper-edge clearance and ADR 0147 supported-span hole screening;
never add a historical centre-layer microvia. Each attempted search is bounded
to 500,000 nodes; no adopted new route may exceed 120 mm. Same-net source
items, individual actual connected filled components and other disconnected
groups may be targets; a shared net/zone name is insufficient contact evidence.

Do not modify the selected source or adopt a search result directly. Reject
any split of the 216 current groups, native/physical disagreement, altered
part/pad/field/pose, old copper/type/profile change or additional native DRC
finding. Any new successor requires the full source/replay/inverse/orphan/
contact/hole/fault/visual gates and exact original 104 payloads under only the
existing U48/U52 transforms. Supply routing here is CAD continuity only; no
current, protection, NTC, timer, default-off or electrical/return/thermal/stack/
process qualification changes. Zero opens and Gate A remain open; fabrication
is prohibited.

Permit the existing ADR 0166 native-screened eight-neighbour 0.050 mm grid as
an alternative read-only search: each diagonal uses an exact native segment
clearance test, Euclidean step cost and the conservative four-neighbour goal
lower bound divided by sqrt(2). Keep the same source, profiles, per-attempt
500,000-node and adopted-route 120 mm bounds. Grid misses are finite study
results, never general impossibility claims.
