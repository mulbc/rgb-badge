# ADR 0199: Fixed-contact supply resistor discovery

Date: 2026-11-16
Status: Accepted for read-only geometry discovery only.

The completed sensor studies select no successor. Inspect a smaller independent
opportunity from the immutable selected 28-open source: exact R71
ERJ2RKF8873X, R21/R11 ERJ2RKF1001X. Each has an isolated supply pad 1 and
an already connected pad 2. Read-only rotate each to cardinal orientations
about its exact fixed pad-2 centre, preserving all source copper and all other
parts/poses. No substitution, value/net/polarity change or current limit change.

Require unchanged local pad geometry/nets, native foreign/no-net copper and
actual board-edge clearance, all fixed component courtyards, every original
direct pad-2 copper contact on its source layer, and every original filled
pad-2 plane contact. A useful supply contact must touch actual retained
same-net source copper or an individually witnessed filled unit from the
existing main supply group. Record obstructions and all exact candidate poses.
Write no PCB; no source retirement, new via, rule exception or approval is
implied. A clear pose or contact requires separate complete prototype scope
and all original-group/native/physical/exact104/source/replay/inverse/contact/
hole/fault/visual gates before selection. All existing electrical/part/process/
fit/stack/Gate A and fabrication holds remain unchanged.
