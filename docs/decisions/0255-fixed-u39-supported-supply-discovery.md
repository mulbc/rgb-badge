# ADR 0255: Fixed U39 supported supply discovery

Date: 2026-11-20
Status: Accepted for bounded read-only additive discovery.

ADR0254's B-only source graph exhausts110 nodes without a main-rail join.
Every original part, source Cu and qualification boundary remains unchanged.

Extend only the same fixed-U39 supply discovery to B/In4 with at most one
new supported0.30/0.10 mm B/In4 microvia. Keep the0.025 mm eight-neighbour
lattice relative to the actual source pad, original ROI,≤100,000 nodes and
≤12 mm complete ordinary0.20 mm conductor. Source B steps precede the
single transition; In4 steps then reach actual original main32-pad +3V3_USB
Cu. Screen exact native source Cu/pads on both layers and every source hole
for each candidate access. Do not waive unsupported old-hole overlap or
add any other span, centre or through via. Recheck merged segments and the
actual retained main-group witness. Write no PCB.

Keep exact U39/programming resistors and C50/C51 roles, all original groups
and attached source Cu, thermal reservation, thresholds, currents, NTC/timer/
default-off and bypass/return/thermal qualification unchanged. A complete
22-open successor requires a separately frozen plan and all native/physical,
exact104, source/identity/profile, hole/replay/inverse/orphan/fault/visual
checks. Controlled-stack/process/fit and independent Gate A/fabrication holds
remain open; no hardware performance or release is inferred.

The first pad-relative graph exhausts110 B nodes; all110 proposed accesses
fail Cu and none reaches hole checking. The manufacturer pad centre x=56.885
is offset from the existing0.025/0.050 mm routing lattice. Recheck the same
single-via topology at nearby global0.025 mm capture points within0.025 mm
of each reachable B node, connecting the actual node to the exact capture
by a separately native-screened ordinary B segment. Its physical length
counts in the same12 mm bound; the via remains exactly at the tested global
capture coordinate. Preserve every other source/native/hole/width rule.
This second grid phase does not establish any join without full verification.
