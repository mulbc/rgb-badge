# ADR 0173: Complete local TMP390 restoration templates

Date: 2026-11-15
Status: Accepted for read-only complete-circuit discovery only.

ADR 0172 finds three pad/courtyard/ordinary-neck/capture-clear sensor poses.
Continue only those exact recorded poses and their neck/capture coordinates on
immutable 28-open source. Keep R89/R90 at their exact current poses and restore
their actual pads as obstacles. Omit only the same exact seventeen-item local
cohort in memory after recording its complete original native contact catalog.
Retain every other source item/type/pose/pad/field/profile and provisional hold.

Read-only screen ordinary 0.20 mm B.Cu straight/one-corner/two-corner local
paths for SETA–R89.1, SETB–R90.1, OUTA–OUTB and their original retained TEMP_OK
via interface at (56.935,14.750) mm. Bound each new local path to 8 mm; retain
actual mutually screened supply neck/capture and moved own foreign pads.
Require each programming and resistor-ground pad within 3 mm of the relevant
sensor pin, the unchanged thermal reservation/movement/bypass bound, and actual
original connected GND fill/copper contacts for all local grounds. All original
external cohort contacts and branches remain restoration obligations; a clear
local template alone is incomplete.

A supply capture still needs a route to the original +3V3_USB group and final
filled-plane continuity. No PCB, retirement, new pose or successor is selected
by this discovery. Before implementation freeze every replacement, supply/
return path and retained interface in a further complete-circuit decision.
Full 216-group/source/native/physical/exact104/contact/hole/replay/inverse/
orphan/fault/visual gates apply. Thresholds, thermal-error allowance, current,
NTC/protections/timers/default-off and all qualification/Gate A holds remain;
fabrication is prohibited.
