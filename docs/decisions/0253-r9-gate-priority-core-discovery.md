# ADR 0253: R9 gate-priority core discovery

Date: 2026-11-20
Status: Accepted for bounded read-only discovery.

ADR0252's complete In3 graph exhausts3,271 nodes from66 gate roots to92
qualified mechanical centres while carrying the proposed Blue left capture.
That capture is a proposed obstacle, not original retained source copper.

Independently repeat the same bounded native lower/core graph with only that
unselected Blue In3/In4 capture omitted. Keep the mandatory ordinary In4
left stem and every original source item except the one prospectively
replaced Blue segment. Use the same source-qualified92 centre points and
actual gate roots, native0.20 mm In3 graph, source/new mechanical/support
hole checks,≤6 mm lower conductor and original ROI/node limits. No new
part move, source omission or via policy change is permitted.

A result only reserves a complete lower gate interface. A later discovery
must restore Blue's whole original pad group and all seven original contacts
with supported color captures/path around that reserved interface, and then
restore the full exact R9 supply and upper gate route. No PCB is written and
no22-open result is inferred. Every old-group/attached-copper, exact104,
source/identity, replay/inverse/fault/visual and electrical/process/Gate A
qualification hold remains mandatory; fabrication is prohibited.

The conservative graph to the original92 centres exhausts3,924 nodes.
Those centres had been screened with the proposed Blue capture present.
Rescreen all7,381 original mechanical coordinates without that proposed
capture, retaining only the mandatory In4 stem, all original source Cu
outside the one Blue item, exact root/lead rules and full source/new holes.
Use any newly qualified centres in the same bounded In3 graph. Record this
as further partial gateway discovery, with no inferred color restoration.
