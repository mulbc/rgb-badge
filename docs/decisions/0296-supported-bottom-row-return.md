# ADR 0296: Supported bottom return for the front row

Date: 2026-11-24
Status: Accepted for bounded RAM-only continuity discovery.

The wider supported F/In2/In3 graphs remain bounded or exhausted without
an accepted row join. Retain the exact source/cell/cohort and corridor,
ordinary0.20 mm Cu,18 mm new conductor and full preservation requirements.
Permit one further supported aligned In3/In4 plus In4/B0.30/0.10 mm
microvia pair, followed by ordinary B routing to actual retained ROW04 Cu
or pads. The earlier F/In1/In2 stack and optional supported0.50/0.30 mm
In2/In3 buried transition are unchanged. At most five new holes are used;
no new centre microvia or through hole, extra retirement or rule change.

Search each original/alternate cell at0.050 mm/300000 states within
x72..90/y7..22 mm; permit0.025 mm/300000 states if the coarse graph fails.
All source and mutual native drill clearances, supported-disjoint/adjacent
outer-stack exceptions only, and actual source/new Cu remain mandatory.
The central mechanical hole may not align with an outer microvia.

Require ROW18/VLED40/GND197/gate4 and209 original groups with only selector
pending, all19256 retained source Cu/no orphans/21 matching opens. The
respective proved selector must subsequently yield20 opens/all210 original
groups before separate exact PCB qualification. No partial selection or PCB
write. Original DRC/replay/inverse/fault/visual/part/timing/electrical/stack/
independent Gate A holds remain; fabrication is prohibited.
