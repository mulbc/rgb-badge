# ADR 0210: Contact-preserving R11 escape discovery

Date: 2026-11-19
Status: Accepted for read-only native escape discovery only.

Continue from the qualified immutable 27-open R21 source, SHA-256
e7748bee49f33b3b5c021c9215d441a047718b284e3a1ee27975e3832ddfb5d2.
The earlier small-translation screen required a nearby main-supply target,
which excludes a useful off-pad gateway farther from that target. Recheck
its clear R11 cardinal poses and ±0.250 mm / 0.025 mm translated pad-2
centres against the actual new parent; preserve every original direct gate
copper contact, exact local pads/part/net identity, fixed courtyards, source
foreign/no-net copper and actual edge rules. Keep all original copper and
every other part fixed. In particular retain the original R11 gate via and
all original ground traces; no earlier unselected substitution is adopted.

Read-only sample supported 0.30/0.10 mm B/In4 captures and optional aligned
In3/In4 captures at 0.025 mm centres within x=70.750–74.750 /
y=2.250–5.750 mm. Require an ordinary straight 0.20 mm B supply neck
≤1.250 mm from the actual moved R11.1, clearing both its own gate pad and
all retained source copper. Include mutual capture/neck and full-board hole
checks. A candidate must either touch actual retained main VLED copper on
an active capture layer or provide clear supported In3 access; do not infer
an absent supply plane or count a disconnected same-net island as main VLED.
Check exact source declarations/identities; use a fresh footprint per pose.

Write no PCB. A gateway is incomplete until the complete supply join retains
all 215 current physical groups, old gate contacts, matching reduced native/
physical opens, exact104 and every full successor source/replay/inverse/
contact/hole/orphan/fault/visual gate under a separate exact prototype scope.
No new centre/full-span via, smaller feature, source retirement, current/
value/protection/default-off or electrical/thermal/part/stack/process/fit/
Gate A/fabrication hold change is authorized.
