# ADR 0298: Route the complete cell with the proved selector present

Date: 2026-11-24
Status: Accepted for bounded RAM-only complete continuity discovery.

Include each cell's exact separately frozen, native-replayed selector route
before the ADR0297 row search. This makes the real selector conductors and
hole part of every source collision/hole screen, avoiding independent-route
crossings. Keep each cell's fixed poses/111 prospective omissions/ten fixed
conductors and the exact respective proved selector. No physical routing
allowance, rule/current/profile, part or retirement change is added.

The starting RAM state must pass21 matching opens with only ROW04 split,
all209 other original groups and19256 retained source Cu/no orphans.
Require the completed candidate to pass20 matching opens/all210 original
groups, ROW18/selector3/gate4/VLED40/GND197, all retained source Cu and
all source/new mutual Cu/drill policies. The row bounds remain18 mm,
x72..90/y7..22 mm, two supported F/In1/In2 outer stacks,0.050/0.025 mm
and300000 states. No partial candidate or PCB write is permitted.

A complete RAM result still precedes separately frozen PCB qualification
with original DRC/replay/inverse/fault/source/visual checks. Part/timing/
electrical/thermal/stack/process/fit/independent Gate A holds remain;
fabrication is prohibited.
