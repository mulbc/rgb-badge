# ADR 0238: Row-zero supported supply access discovery

Date: 2026-11-20
Status: Accepted for exact read-only outer-layer supply access discovery.

Use only the selected 24-open source SHA-256
230b0c9f456837a0dd1b5e432497aa5223da95334ac2909ff8cd39d2edea804a.
R6's complete pull-up/gate connection is now preserved. PAIR01.4 remains an
original isolated VLED power pad on F at (75.450,5.225) mm. Do not move any
part or omit, retire, replace or retype any source Cu in this discovery.

Screen supported 0.30/0.10 mm F/In1 and In1/In2 accesses at that exact pad
centre. Check every source pad/track on the actual spanned layers, including
all R6 additions, and full source/new drill pairs. An aligned supported
adjacent pair may qualify only under the existing CAD hole policy; via-in-pad,
filling/capping and fabricator stack remain unqualified. Identify actual
R18.1-connected VLED ports/polygons on In1/In2; a zone name or pre-refill
collision alone is not evidence of final restoration.

If accesses clear, a separately recorded bounded 0.20 mm In1/In2 supply
search may restore the original isolated pad to actual main VLED within the
existing ≤6 mm row/high-side conductor study bound. No new central or through
transition is authorized. Keep every original 212 group, main GND197 and
main VLED37 intact; a complete qualifying join would make main VLED38 and
23 matching native/physical opens. Require a frozen complete plan and all
full successor checks before writing/selecting a PCB.

This is unbuilt CAD geometry discovery. The source's current/protection/
default-off limits and firmware are unchanged. No row-current capacity,
thermal, timing, return, trial-package, fit/process/controlled-stack or hardware
qualification is inferred; all remain open, and independent Gate A continues
to prohibit fabrication. Write no PCB during this access screen.
