# ADR 0184: Local native diagonal and fine-grid refinement

Date: 2026-11-16
Status: Accepted for ignored bounded geometry search only.

Dense witnessed-plane targets alone do not finish the exact ADR0182 prototype.
Permit the previously established ADR0166 native-screened eight-neighbour
method inside the same x=52–64/y=12–21 mm window, first on a 0.050 mm grid and
then 0.025 mm. Every diagonal uses exact native 0.20 mm segment-shape clearance,
Euclidean step cost and the existing four-neighbour goal lower bound divided
by sqrt(2). Record actual step/origin/neighbours and weighted-search semantics;
claim no optimality or general infeasibility from a finite miss.

Retain ADR0183's actual individually copper-witnessed plane endpoints and native
refill proof. Keep all source/cohort/pose/profile/width/via/hole/edge rules,
500,000-node limits, exact per-join/per-net copper budgets and current-group
preservation/undo guards unchanged. No new retirement, part, layer span, centre
microvia or routing-rule change. Ignored predecessor tools stay immutable.

A successful path remains incomplete until all original 216 groups/interfaces
and complete sensor circuit, matching native/physical reduction below 28,
exact104 and every independent source/contact/hole/replay/inverse/orphan/fault/
visual gate pass. Every electrical/thermal/current/threshold/protection/NTC/
timer/default-off/part/HDI/stack/process/fit/Gate A/fabrication hold remains.
