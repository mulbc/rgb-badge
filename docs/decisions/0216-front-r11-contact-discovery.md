# ADR 0216: Front-side R11 contact discovery

Date: 2026-11-19
Status: Accepted for read-only native discovery only.

The local B prototype is unselected. Native subset controls establish that
its 65-item retirement alone preserves all 196 main ground pads, while the
new B placement and leads split the ground plane. Supported ground access
finds six incomplete PAIR08 gateways and none for PAIR07. No ground repair
or successor is adopted.

Read-only screen exact R11 on F near existing actual main VLED F copper,
x=76–82 / y=8–12 mm, cardinal orientations at 0.050 mm centres. Preserve
all other parts, both-face courtyards, source geometry and rules. A side flip
must preserve exact pad/part/net identity and package dimensions; it is a
placement study, not an assembly/fit approval. Keep all F LED courtyards.

First prove the exact 25-item original gate prefix has only original R11.2
and the retained F endpoint cluster at (78.300,10.800) mm as outside
interfaces, without any zone/other branch. Native contact discovery finds
four overlapping retained ordinary stair wires at that endcap:
`bdf3e2be-ec90-5848-83cf-76e3dfb7171f`,
`88ac0e8a-2225-5b70-a89a-b8a5aac76824`,
`af1c44e0-5935-5c37-8c11-ac9c67fce62b` and
`1dd5131b-4d4a-52d1-b368-7b86a71a4244`. Keep every one attached
and require the new gate endcap to touch all four directly.
Only that recorded prospective prefix may be omitted in this read-only
screen. Require mutually native-clear ordinary 0.20 mm F supply and gate
leads, each at most 2.5 mm, to actual retained main VLED F copper and that
exact retained gate endpoint. Add no via or other prospective retirement.

Write no PCB. A complete prototype requires a separate frozen exact pose/
cohort/lead plan and all original 215 groups, reduced matching counts,
exact104 and every source/serialized/replay/inverse/hole/orphan/fault/visual
gate before selection. No current/value/protection/default-off, electrical/
thermal/bypass/assembly/fit/stack/process/Gate A/fabrication hold changes.
