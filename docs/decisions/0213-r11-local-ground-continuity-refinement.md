# ADR 0213: R11 local ground-continuity refinement

Date: 2026-11-19
Status: Accepted for bounded ignored native prototype comparison only.

The exact ADR0212 prototype joins main VLED (36→37 pads) and retains the
complete four-pad gate with no new orphan copper, but native refill splits
the old main ground group. Its 28 native/physical opens and lost original
GND continuity reject it; the qualified source remains 27 opens.

Compare only the nine ADR0211 mutually clear cardinal poses: R11 centre
x=77.750 mm, y=13.550–13.950 mm in 0.050 mm steps, 90 degrees. Keep the
exact same 65 prospective retirements and every other source item/part/rule.
For each pose add just the two recorded ordinary 0.20 mm B straight leads
to the same exact supply and PAIR06 gate endpoints. Perform actual native
refill and original-group/attached-copper comparison; a geometrically clear
pose is not sufficient. Write ignored comparison probes only.

Select no board unless a separately frozen exact plan passes every ADR0212
successor gate. Add no ground route, via, additional retirement, smaller
feature, part substitution or safety/current/qualification/fabrication change.
