# ADR 0149: Additive supply and return continuation

Date: 2026-11-14
Status: Accepted for ignored feasibility; no successor selected.

Use only the immutable ADR 0142 selected 30-open source, SHA-256
`90db778d8e44b2c71ab5e1f5d8a1c586ee71c25d46892b1406c4792ac7720abd`.
The read-only live terminal inventory identifies remaining groups on GND,
VLED, +3V3_USB, +BAT_GAUGE_SW and VBUS_CONNECTOR. Test additive ordinary
0.20 mm supported-layer paths between actual disconnected groups, including
individually filled-zone targets with actual source-group copper witnesses.
Use ADR 0147's fixture-qualified disjoint supported-span drill prefilter only;
retain all overlapping/unsupported/through/NPTH checks, foreign/no-net copper,
board edges and exact native rule/profile bytes. Use adjacent 0.30/0.10 mm
microvias and central In2/In3 0.50/0.30 mm mechanical buried vias only.
No source item, part, pose, net, pin map or existing drill type may change.

Preserve all 218 source groups at each filled candidate. A smaller native count
alone is insufficient: independent physical connectivity and source preservation,
complete original 104 finding comparison, exact addition/contact/hole ledger,
stable independent replays, inverse-source/orphan proof, native fault guards,
portable source checks and visual review remain mandatory before selection.
Any abandoned or partial bridge remains ignored and unselected.

These are CAD connectivity bridges only. A 0.20 mm exploration path is not a
current-capacity, return-path, thermal, transient or electromagnetic assessment.
Do not raise any current/voltage limit, alter protections/NTC/timers, bypass
hardware current control or change default-off behavior. All electrical, part,
process/HDI/controlled-stack/fit qualification, the 557 historical centre vias,
and independent Gate A remain unresolved. No fabrication release is authorized.
