# ADR 0207: R11 supported gate escape discovery

Date: 2026-11-16
Status: Accepted for read-only complete-interface discovery only.

The ADR0206 ground substitution retains every original branch/group and
exact104 at 27 opens. The exact R11 pose and supply lead then clear native
copper, but its 611-node bounded B gate graph cannot reach the retained
old gate via. Keep the same exact five-item prospective source cohort,
R11/R21 poses, VLED leads and every other source item/rule fixed.

Read-only screen supported 0.30/0.10 mm B/In4 gate captures at native
0.050 mm B nodes actually reachable from fixed R11.2 under ADR0205's
≤6 mm / 50,000-node B bounds. Preserve exact ordinary 0.20 mm B edges,
actual source edge, foreign/no-net and mutual proposed copper, and full-board
hole policy. Record optional aligned supported In3/In4 access; no centre or
full-span transition. Retain the actual path and shortest B length for each
capture and record any actual retained main ROW_GATE_05 copper contact.

Write no PCB. A supported escape is not a complete gate join. Any further
prototype requires separate exact scope and complete immutable group,
native/physical/exact104/source/contact/hole/replay/inverse/orphan/fault/
visual gates. No additional source retirement, part/value/current/protection/
default-off or electrical/thermal/stack/process/fit/Gate A/fabrication hold
change is authorized.
