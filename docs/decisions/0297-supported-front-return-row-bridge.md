Date: 2026-11-24
Status: Accepted for bounded RAM-only continuity discovery.

The monotone wider layer graphs find no accepted row join. Test a real
F-to-In2-to-F bridge from actual new ROW04 group Cu/PADs to actual retained

an aligned supported F/In1 plus In1/In2 0.30/0.10 mm microvia pair.

through hole, additional source retirement or rule/current change.
