# ADR 0163: Read-only heartbeat front-layer access discovery

Date: 2026-11-15
Status: Accepted for read-only native geometry discovery only.

The selected source remains the immutable 29-open inverter checkpoint. The
private USB bridge prototype preserves all groups and exact findings, but
its next input routes still split USB/battery groups and remain unselected.
Investigate a front-layer route that would avoid those routing-plane domains.
The original R103/U3/U47 heartbeat group reaches B/In4 only; no existing F/In1
endpoint is assumed.

Use the exact ADR 0154 prepared input, with source project/rules verified
byte-identical. Read-only screen a local U48 front-access cohort: ordinary
0.20 mm In3 lead from (110.000,27.250) to (109.500,27.250) mm; supported
0.50/0.30 mm In2/In3 mechanical buried via there; ordinary 0.20 mm In2 lead
to (109.000,27.250) mm; aligned 0.30/0.10 mm In1/In2 and F/In1 microvias at
the final point. No mixed-diameter aligned stack is allowed. Test all actual
foreign/no-net/mechanical copper, mutual geometry, all source holes under
ADR 0147's bounded span model and board edges. If this exact cohort fails,
report the blocker before expanding positions. No PCB is written.

For the original R103/U3/U47 source group, read-only screen provisional
0.50/0.30 mm F/B through captures physically touching actual original B/In4
source copper. Sample actual source-pad centres within ±0.400 mm and points
along actual source In4 tracks at 0.050 mm spacing with ±0.200 mm offsets.
Require positive native copper contact, full six-layer foreign/mechanical
copper screening, complete unchanged 0.25 mm hole clearance and 0.50 mm
copper-edge allowance; no disjoint exception applies to full-span holes.
Skip duplicates and record exact source UUID/contact/position witnesses.
No pin, part, pose, source copper, field, net or profile/rule change.

Freeze a complete successful access cohort before any implementation. Refills
must preserve all 217 selected-source groups before any later F/In1-only signal
search. The existing 120 mm signal/1,200,000 node bounds, all full native and
independent source/finding/contact/hole/replay/inverse/orphan/fault/visual gates
remain. Full-span drilling, aligned microvia filling, return/timing and current
capacity remain unqualified. No current/protection/default-off or fabrication
boundary changes; zero opens and every engineering/Gate A hold remain open.
