# ADR 0276: Front PAIR05 and pull-up module discovery

Date: 2026-11-24
Status: Accepted for bounded read-only placement discovery.

Fixed PAIR05/09 pockets and PAIR07 lower/centre searches find no complete
join. Preserve selected22-open source03e74104c51811a1. Screen only trial
PAIR05 NTLJD3119CTBG_TRIAL_ONLY and exact R10 ERJ2RKF1001X as a possible
F-side module, keeping numbered nets/local lands/fields/values unchanged.
Source R10 is B47.250,4.250/180 degrees, not a guessed adjacent resistor.
Manufacturer evidence re-read: cached onsemi NTLJD3119C/D April2024 Rev6
pages1/10 and Panasonic ERJ29-May-2025 part coding/package dimensions.
No trial-package or electrical acceptance is inferred.

First screen PAIR05 F over x42..86/y7..14 mm,0.10 mm/cardinal orientations,
using top-bottom flip, actual F courtyards and fixed copper/pad clearance.
Restore its three real ordinary0.20 mm package straps; only unchanged
intrinsic own-package PAD-PAD pairs may be excluded from preliminary pad
screening. New tracks/vias never receive that exception. Test supported
0.30/0.10 mm F/In1 supply access and aligned F/In1+In1/In2 ground access
at actual numbered pads, with source/new Cu and all source/mutual holes.
Require actual original VLED In1 and GND In2 filled-polygon contacts;
these are preliminary plane witnesses, not a completed live-group join.
Then study actual front ROW04 output access and R10 poses within3 mm of
the gate, with all other481 parts fixed. No new centre/through via or
physical/profile/current/default-off/protection change is authorized.

No source Cu may retire before exact typed private-leaf/outside-contact
cataloguing and a separate bounded replacement decision. Write no PCB.
Only a complete20-open candidate restoring all210 original groups,
retained attached Cu, GND197/VLED40 and full gate/row/selector groups can
advance to separate exact104/replay/inverse/fault/source/visual qualification.
Power-copper/return/thermal/electrical/trial-package/stack/process/assembly/
fit and independent Gate A holds persist; fabrication is prohibited.
