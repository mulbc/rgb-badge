# ADR 0251: R9 local color hop discovery

Date: 2026-11-20
Status: Accepted for bounded read-only discovery.

ADR0250 preserves all15 original contacts and passes holes, but fails native
Cu at its red captures/lead against ROW_03_A and existing green-channel
routing. No red source retirement is selected. Keep COL_05_R and every
other original source item except the one prospectively replaced Blue item
from ADR0249 during this independent alternative.

Use a short local Blue In3 hop returning to its old In4 channel before the
existing COL_12_G In3 vertical at81.850. Keep the original left stem and
supported left capture78.500,8.900. Discover a supported In3/In4 Blue return
capture at0.050 mm points in x=80.250–81.500 /y=8.800–9.000. Restore the
actual original right port84.750,8.900 with ordinary In4 tail via the return
capture's x coordinate at y=8.900, preserving all seven original contacts.

Sample supported gate B/In4+In3/In4 capture pairs inside the unchanged
PAIR04 gate body at0.050 mm points x=79.500–80.000 /y=8.750–8.950,
prioritizing79.750,8.750. Require actual original gate-body contact, native
source/fixed/new Cu and full source/new drill checks. All original red and
boot wiring remains fixed. The northward gate access may permit a local
Blue path below it; accept this only after native geometry verification.

For each qualified gate pair, discover ordinary0.20 mm In3 Blue conductor
from the left capture to alternative qualified return captures at0.025 mm
eight-neighbour steps in x=77.000–85.500 /y=7.000–10.500,≤100,000 nodes
and≤12 mm complete replacement conductor including original-contact stems
and return tail. Recheck merged segments. No new centre/through via or PCB
write is permitted. A clear color gateway is only a partial gate interface;
full R9 supply/gate restoration and every original-group/retained-copper,
exact104, source/identity, replay/inverse/fault/visual and qualification hold
remain prerequisites for22 opens. Fabrication is prohibited.
