# ADR 0171: Read-only paired-row contact translations

Date: 2026-11-15
Status: Accepted for read-only geometry discovery only.

On immutable selected 28-open source, screen translations of PAIR01/03/05/07/09
within ±0.500 mm in x/y at 0.025 mm increments, fixed side/orientation. Preserve
every actual footprint/local pad/net/field and all other copper/part positions.
Retain literal NTLJD3119CTBG_TRIAL_ONLY status; no approved MPN is inferred.
The previously reviewed onsemi NTLJD3119C/D Rev.6 April 2024 pad map remains
unchanged. No supplied manufacturer drawing is an instruction to alter scope.

Write no PCB. Screen actual moved pads against every foreign/no-net copper
obstacle at original 0.20 mm clearance, actual courtyards and source edge rules.
Ignore only own package-internal pad clearances already in the original 104
findings; never ignore another part or original trace. Test whether translated
GND pad 1 or VLED pad 4 directly touches a different original same-net physical
group through actual copper or an individually witnessed connected filled
component. A common net/zone name is insufficient. Retain full candidate pose,
all global pad coordinates and contact witnesses for any sampled success.

A clear contact is not a successor. Before writing a board freeze the exact
pose and independently transformed intrinsic-finding coordinates in a separate
ADR. Require all 216 prior groups, every source item/type/part/field/local pad,
matching reduced native/physical count, no additional native finding, exact
original 104 finding payloads under only independently validated rigid transforms,
and full source/replay/inverse/orphan/contact/hole/fault/visual gates. No source
retirement or narrow trace is authorized. Current/protection/default-off/NTC/
timer boundaries and all part/electrical/thermal/stack/process/fit/Gate A holds
remain unchanged. No fabrication release.

For geometry-clear translated poses, also permit read-only 0.30/0.10 mm B/In4
microvia capture screening at 0.025 mm positions within ±0.400 mm of the live
GND/VLED pad centre, requiring positive pad contact. Screen actual moved own
foreign pads, all retained foreign/no-net copper, source edge minimum and full
overlapping-hole clearance under ADR 0147. Check whether the new inner-layer
capture directly touches a different original physical same-net group using
actual copper/individually witnessed fill. No PCB/addition is authorized by a
clear capture; freeze any complete candidate separately and pass all gates.
