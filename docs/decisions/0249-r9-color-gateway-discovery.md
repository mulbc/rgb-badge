# ADR 0249: R9 single-color gateway discovery

Date: 2026-11-20
Status: Accepted for bounded read-only discovery.

ADR0248 exhausts10,171 reachable B nodes and tests2,591 B/In4 candidates;
none clears source Cu. Do not infer an acceptable gate transition from the
118 earlier front supply poses. The23-open PCB remains immutable.

A native counterfactual contact probe identifies one exact COL_05_B In4
segment b5fba1d8-a4db-52d4-aa02-4b3fb7d808ee,
(84.750,8.900)→(77.950,8.900),0.20 mm, as the local gate-access blocker.

y=7.000–10.500 mm,0.025 mm eight-neighbour steps,≤100,000 nodes and
≤12 mm. Recheck simplified segments and actual original contacts. If fixed
source/hole prerequisites fail, record them before any route search.

or full gate join. A later exact22-open prototype must restore the complete
