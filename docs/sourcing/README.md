# Sourcing records

Candidate-part comparisons, supplier correspondence, exact pack drawings and frozen quote BOMs belong here. Marketplace listings demonstrate possible availability only; a part becomes approved only after its manufacturer, exact MPN, datasheet, package, pinout and relevant safety/optical documentation are verified.

Critical ICs should come from manufacturer-authorized distribution or a traceable assembler supply chain. Anonymous marketplace LiPo cells and silent PCBA substitutions are prohibited.
