# Unlinked 3.3 V application converter candidate

The separate [VLED converter candidate](../vled-converter-capture-contract.md) now stages thirteen exact-MPN items in vled-converter.kicad_sch. It is default-disabled and remains unlinked until protected SYS and the hardware display interlock are captured.

The separate [VLED local layout trial](vled-layout-trial.kicad_pcb) uses the same thirteen project-local footprints and their exported schematic pad nets at the coordinates of the [lower-right cluster screen](../../../../mechanical/dual-row-package-screen-2026-10-06.md). It has a local study outline, no tracks, vias or copper zones, and none of the neighbouring final-board circuitry. Generate and round-trip-check it with KiCad's bundled Python: `/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3 tools/generate-vled-layout-trial.py`. KiCad 10.0.6 loaded and plotted its actual pads. [Native local-board DRC evidence](../../../../docs/development/vled-layout-trial-2026-10-06.md) records zero geometric violations and thirty expected open connections when run with desktop access. This is not a routed/full-board DRC pass. This file is a placement study, never a fabrication source.

The separate [display-interlock placement trial](display-interlock-layout-trial.kicad_pcb) groups the 31 captured interlock footprints and carries their exported pad nets. Generate it with KiCad's bundled Python using `tools/generate-display-interlock-layout-trial.py`. [Native DRC findings](../../../../docs/development/display-interlock-layout-trial-2026-10-13.md) show eight intra-footprint clearance violations at the present 0.20 mm rule and 76 expected unrouted connections. It has no routed/full-board DRC pass and is never a fabrication source.

The [full-footprint 120 mm coupon trial](full-coupon-placement-trial-120mm.kicad_pcb) stages every captured footprint and native pad net on two faces of a provisional six-layer board while retaining all 32 current row transistors. The linked study paths include four E0/E1 support nets, both J1 VBUS pads to E0/C60, E0-to-C61, E1-to-C52, C52-to-U41/C56, the local R93 ILIM/ground loop, C62/C57 timing-capacitor and both eFuse IC ground returns, the second J1 GND contact, E1 pad 2, two U37-to-L2 switching nets and 16 Everlight half-row anode trunks. Nearly all other routing remains open. Its [source and DRC record](../../../../docs/development/full-coupon-placement-trial-2026-10-13.md) explains why this larger board is a layout discovery artifact, not the accepted 110 mm badge PCB or a release output.

The separate [red-column HDI trial](red-column-hdi-trial-120mm.kicad_pcb) copies that full-footprint study and adds tentative pad-centred F.Cu–In1.Cu microvias for all sixteen red cathode columns. [Its review](../../../../docs/development/red-column-hdi-screen-2026-10-14.md) records native DRC and the still-open green/blue routing and manufacturing process. Generate it with `tools/generate-red-column-hdi-trial.py`; it is not the canonical PCB or a fabrication source.

The [114 mm grouped placement study](paired-charger-placement-only-114mm.kicad_pcb) uses actual KiCad pads for the provisional paired-row and charger-group XY option, with two projected final drivers. It is unrouted and the row-pair/extra-driver pads are netless. [Its native DRC record](../../../../docs/development/paired-charger-114mm-placement-study-2026-10-14.md) identifies 104 known fine-pitch pad-gap violations and a capped unconnected listing; it does not approve the row substitution, enclosure size or fabrication. Generate it with `tools/generate-paired-charger-114mm-placement.py` using KiCad's bundled Python.

`3v3-converter.kicad_sch` contains the exact `TPS631000DRLR`, one Murata `DFE252012P-1R0M=P2` 1 µH inductor, two `GRM187R61A226ME15` input capacitors, two `GRM219R60J476ME44` output capacitors, the Panasonic 511 kΩ / 91 kΩ feedback pair, and a 100 kΩ EN pull-down. The source checker verifies nine items, all 24 pins and the two *local* LX switching nodes. Regenerate deterministically into a new directory with `python3 tools/generate-coupon-3v3.py --output /tmp/rgb-3v3-candidate`; compare with this source before replacing it.

This historical candidate remains **unlinked** for deterministic comparison. The battery pack, charger, gauge pole, LED supply and whole-board OFF leakage remain uncaptured or unqualified.
