# Coupon project-local 3D models

Store reviewed STEP models used by Coupon Rev A here. Record the source, licence, exact MPN and dimensional cross-check for every imported model. A model is visual/mechanical evidence only; it does not validate a symbol or footprint.

This directory is intentionally empty at scaffold creation.
