# Manufacturing releases

This directory will contain immutable coupon and badge fabrication releases. Each release must include Gerbers, drill files, BOM, placement file, assembly drawing, stack-up, factory firmware, test instructions, ERC/DRC/DFM evidence, SHA-256 manifest and known issues.

Generated files outside an approved release are ignored. No current directory is authorized for fabrication.
